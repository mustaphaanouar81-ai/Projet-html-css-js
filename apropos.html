Le projet

HANSWEAR est un site vitrine de boutique de vêtements en ligne : collections femme, homme, accessoires et promotions. Il a été réalisé en HTML5, CSS3 et JavaScript, sans framework ni bibliothèque, et le code est versionné avec Git (dépôt GitHub).

Fonctionnalités du site

  • Navigation entre les pages et design responsive (media queries)
  • Menu burger pour la version mobile
  • Barre de recherche d'articles sur les pages produits
  • Validation du formulaire de newsletter en JavaScript
  • Compte à rebours de la promotion et animations au défilement
